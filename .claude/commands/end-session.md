Wrap up the current session:

1. Run /update-changelog if any features or fixes were completed this session
2. Run /update-docs if a milestone was completed this session
3. Stage all changes: git add .
4. Write a clear, specific commit message describing what was accomplished
5. Commit and push to GitHub

Do not skip the commit if there are uncommitted changes. 
Do not use vague messages like "updates" or "misc changes".
