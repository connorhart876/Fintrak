# Goal

To build a multi-user personal finance tracker web app where each user logs in to independently track their own expenses, income, and financial situation. All user data is completely private and isolated. Key features include: authentication, transaction tracker, budget tracker, accounts tracker, and investment portfolio tracker.

## Functionality Milestones

| Milestone | Features |
|-----------|----------|
| MVP | Email + password login/authentication. Add expense: amount, date, category, title. Transaction list: scrollable, sorted by date. Fixed categories (food, transport, bills, etc.). Monthly totals. Delete transaction. Single-page app (transactions only). |
| v1 | Multiple pages: Dashboard, Transactions, Budget. Edit transactions. Income transactions. Dashboard: 3 metric cards (income, expenses, net) + spending by category + recent transactions. Transactions: scrollable table. Budget: each category shows a horizontal progress bar; user sets the monthly budget amount per category. Month selector is a pill toggle (← Jun \| Jul \| Aug →) in the page header — never a dropdown. Each month's budget resets independently (no rollover). |
| v2 | Recurring transactions (weekly/monthly auto-log), shown with a loop icon in the transaction list; managed in a dedicated "Recurring" tab showing next fire date, frequency, and a pause toggle. CSV import: drag-and-drop zone → column mapping table → preview step → confirm import (full-screen overlay wizard). CSV / PDF export of any date range. In-app monthly spend report (downloadable as PDF). Savings goals: target amount + deadline + optional account label (e.g. "New Car — $10k — Ally Savings"); deposits toward a goal are logged separately and do not affect account balances or transactions. Goals page: each goal is a card with a circular progress ring, projected completion date, and a quick-add deposit button. Full-text search across transactions. Custom user-created categories + icons. Trend chart: income vs. expenses over last 12 months. Cmd+K command palette for quick-add transaction from anywhere in the app. |
| Later | Accounts page: manually track balances across account types (checking, savings, credit card, etc.). Dashboard updates to show account balances once accounts are built. Net worth tracker: aggregates account balances + investment portfolio value shown as a trend over time. Investment portfolio page: manually log holdings across any asset class (stocks, ETFs, crypto, etc.); live price data auto-fetched for publicly traded assets; analytics include total value, P&L per holding, % gain/loss, and allocation breakdown. Savings goals formally linked to a specific account (upgrade from v2's text label). Auto-categorization of imported transactions. Cash flow forecasting. AI chat. |
| Not in Scope | Not a mobile app (web, desktop-first). No real-time syncing across devices. Doesn't need crypto or stock trading features (portfolio tracking only — no trade execution or suggestions). No tax reports. No advanced forecasting ML models. No integration with accounting software. No email delivery of reports (in-app PDF only). No household or shared budgets — all user data is completely private and isolated. |
